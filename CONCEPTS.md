# Concepts

Shared domain vocabulary for this project — entities, named processes, and status concepts with project-specific meaning. Seeded with core domain vocabulary, then accretes as ce-compound and ce-compound-refresh process learnings; direct edits are fine. Glossary only, not a spec or catch-all.

## Content Ingestion

### Article / Watch Entry
A web document or social media post captured by the user into the local curation database.
*Avoid:* Bookmark, item, post

Each Watch Entry represents a captured URL or post with its full text content, metadata (author, site domain, publication date), user notes, auto-detected category, and AI-generated tags.

### Technical URN
A unique technical identifier (`urn:li:activity:...` or `urn:li:share:...`) generated by LinkedIn for feed posts.

Used as the primary permalink key for LinkedIn posts to prevent link hijacking from post body text or profile call-to-action buttons.

## Intelligence & Synthesis

### AI Synthesis / Summary
A structured, multi-bullet French summary generated on demand using Vertex AI Gemini models.

Presents 3 to 5 key takeaways with bolded concepts, metrics, and technological highlights. Can be generated on the fly during reading.

### Knowledge Base Chatbot
An interactive assistant that answers user queries using the complete corpus of saved watch entries as its context.

### Article Q&A
A focused chat module scoped to a single Watch Entry, capable of combining article body text with targeted web search results when external context is requested.
