## 🚀 Key Highlights

- **Single-Click Ingestion**: Save web articles or LinkedIn posts with full-text body extraction and automatic base domain detection.
- **Dual Reading Mode**: Switch effortlessly between the **Full Article** (`📖 Lire`) and **AI Summary** (`✨ Résumé IA`).
- **Interactive Article Q&A**: Chat directly with any single article using Gemini 2.5 Flash, with automatic web search context fallback when requested.
- **Global Chatbot**: Query your entire curation knowledge base in natural language.
- **Weekly Newsletter Digest**: Generate beautifully formatted Markdown digests categorized by topic in 1 click.
