# Security Policy

## Supported Versions

Only the latest `main` branch of **SYNAPSE** is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:                |

## Reporting a Vulnerability

If you discover a potential security vulnerability within **SYNAPSE**, please do NOT open a public issue.

Instead, please send an email directly to **lucas.heral@artefact.com**.

We will acknowledge receipt of your vulnerability report within 48 hours and provide regular updates on the resolution.
